# Models Directory

This directory stores local weights, tokenizers, and model configuration files for the Small Language Model (SLM) and Sentence Transformer embedding models.

## Planned Models

- **Embedding Model**: `sentence-transformers/all-MiniLM-L6-v2` or `BAAI/bge-small-en-v1.5`
- **Small Language Model (SLM)**: Quantized local model for legal reasoning and citation verification.

## Security Notice

- Large binary weights (`.bin`, `.safetensors`, `.onnx`) are ignored by `.gitignore`.
